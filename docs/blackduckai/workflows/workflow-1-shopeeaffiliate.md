# WorkFlow-1-ShopeeAffiliate

Status: **Main company workflow / source of truth** for BlackDuckAi Shopee Affiliate Facebook content loops.

Owner: Red coordinates the Shopee, Facebook, Brandcreative, and QA specialists.

Trigger command: **`WorkFlow-1-ShopeeAffiliate`**

Former trigger: `ShopeeAffiliate` is deprecated. Use `WorkFlow-1-ShopeeAffiliate` going forward.

## Purpose

Run one complete Shopee Affiliate Facebook campaign loop:

1. Check Shopee API.
2. Check Facebook API.
3. Select one Shopee Affiliate product.
4. Research Facebook Ads Library patterns.
5. Generate three affiliate links.
6. Create five ad images with `gpt-image-2` only.
7. Publish five Facebook image posts as a ladder.
8. Add required comments under every image post.
9. Generate one video with Veo only.
10. Publish the video post.
11. Verify every real action by API readback.

No secrets, tokens, cookies, page tokens, app secrets, or customer-sensitive data belong in this document or in workflow logs.

## Non-negotiable sequence

The workflow must not skip or reorder these stages:

1. API health checks first.
2. Product selection and data verification.
3. Facebook Ads Library research.
4. Affiliate link generation.
5. Five image creatives.
6. Five image posts.
7. Comments under every image post.
8. Veo-only video generation from the image set.
9. Video post.
10. Final verification.

Do not start with standalone text-to-video, slideshow, or a one-off video unless TOP explicitly approves a separate legacy/fallback workflow.

## Approval matrix

Draft/read-only work can proceed without additional approval:

- Shopee/Facebook read-only API checks.
- Product filtering and analysis.
- Facebook Ads Library pattern research.
- Affiliate link generation when part of the requested workflow.
- Draft captions, creative briefs, image drafts, video drafts, and non-secret Obsidian notes.

Latest explicit TOP approval is required before:

- Real Facebook posts.
- Real Facebook comments.
- Deleting or hiding posts/comments.
- Real inbox messages.
- Ads, campaign changes, or budget usage.
- Any use of sensitive customer data.

Accepted approval phrases include: `โพสต์จริง`, `โพสต์ภาพจริง`, `โพสต์วิดีโอจริง`, `คอมเมนต์จริง`, `ทำงานจริง`, and `รันจริงเลย`.

## Product selection

Use TOP's filters for the run. If TOP does not override, use the currently approved ShopeeAffiliate defaults.

For runs like the latest approved bestseller workflow, enforce:

- Category: bestseller / สินค้าขายดี.
- Price: at least 1,000 THB.
- Commission: at least 10% total.
- Special/seller commission required when requested.
- Sold count: at least 500.
- Rating: at least 4.5.
- Product count: one selected product.

Save candidate evidence and the final selected product with numeric proof. Do not select duplicate products unless TOP explicitly allows reposting.

## Product reference image

Download and verify the real Shopee product image before creative generation.

The product reference must be used as the image reference/input so the final ad preserves product identity:

- Shape.
- Color.
- Packaging.
- Logo/model details where applicable.
- Product type.

If the generated result changes product identity, regenerate or stop and report. Do not silently accept product drift.

## Facebook Ads Library research

Use the TOP-approved Ads Library entry point as the research source:

```text
https://www.facebook.com/ads/library/?active_status=active&ad_type=political_and_issue_ads&country=TH&is_targeted_country=false&media_type=all&sort_data[mode]=total_impressions&sort_data[direction]=desc
```

Record patterns only:

- Hooks.
- Pain points.
- Visual composition.
- CTA framing.
- Benefit framing.
- Customer intent.
- What not to copy.

Never copy competitor assets or copy directly.

## Affiliate links

Generate and verify three links:

1. Product affiliate link.
2. Shop affiliate link.
3. Shopee code/deal/discount affiliate link.

Sub IDs may be used internally, but public captions/comments may show affiliate URLs only. Never expose Sub IDs, commission, internal scores, API details, tokens, secrets, credentials, or internal identifiers.

## Public copy rules

All public captions/comments must use the page/admin voice, not an agent voice.

Required tone:

- Thai female admin voice.
- Use `ค่ะ`, `คะ`, and `นะคะ` naturally.
- Keep copy concise and customer-facing.

Never include:

- AI names.
- Agent names.
- `Red`.
- Internal workflow names.
- Internal system names.
- Sub IDs.
- Commission.
- Internal scores.
- Tokens, secrets, credentials.
- Unverified claims.

Acceptable neutral public phrasing includes:

- `ลิงก์อยู่ด้านล่างค่ะ`
- `กดดูรายละเอียดก่อนตัดสินใจนะคะ`
- `เช็กสินค้า ร้านค้า และโค้ดส่วนลดได้จากลิงก์ค่ะ`

## Image generation: gpt-image-2 only

Final ad-image creatives must be generated by `gpt-image-2` / `gpt-image-2-high` only.

Hard rules:

- Use the real Shopee product image as reference/input.
- No non-gpt-image model.
- No silent fallback.
- No generic-background plus manual/PIL product paste workflow as the final creative path unless TOP explicitly approves it.
- If `gpt-image-2` is unavailable, stop and report the error.
- At least two or three images should include a person.
- Keep Thai text short and mobile-readable.
- If Thai text or product fidelity is poor, regenerate.
- No unverified price, discount, rating, warranty, official-store claim, medical claim, commission, or Sub ID in the creative.

Required five-image set:

1. Human Hook — person plus pain/use case.
2. Product Proof — product clearly visible and verified benefit.
3. Human Use Case — person using/preparing/interacting with product.
4. Feature/Benefit — product detail or benefit framing.
5. CTA — summary and click-link intent.

Save the five images, contact sheet, prompts/metadata, model name, and fallback status.

## Image post ladder

After latest TOP approval, publish five Facebook image posts:

- Post 1 attaches image 1 only.
- Post 2 attaches images 1-2.
- Post 3 attaches images 1-3.
- Post 4 attaches images 1-4.
- Post 5 attaches images 1-5.

After each post, verify by API readback:

- Post ID.
- Permalink.
- Caption.
- Three affiliate links.
- No AI/agent/internal names.
- No Sub ID/commission/internal leaks.

## Under-post comments

Every one of the five image posts must have:

1. One link comment.
2. Five image-only comments.

### Link comment

The link comment may contain text, but only customer-facing link labels and the three affiliate links:

- Product link.
- Shop link.
- Shopee code/deal link.

Never include Sub IDs, commission, internal scores, AI names, agent names, `Red`, system names, or secrets.

### Image-only comments

Each image comment must be an image attachment only.

Hard rules:

- Use the five generated ad images.
- No message text.
- No caption.
- Do not write `ภาพเพิ่มเติม 1/5 ค่ะ` or similar text.
- Verify that the image comments have attachments and no visible message text.

## Video generation: Veo only

After the five images exist, generate one video with Veo / Gemini Veo only.

Inputs:

- The five generated images.
- TOP-provided video reference/prompt.
- Strongest human image as the seed if the backend accepts only one source image.
- All five images as storyboard/reference if the backend supports multiple references.

Hard rules:

- Veo only.
- No standalone text-to-video without the image set and TOP reference.
- No local slideshow.
- No ffmpeg slideshow.
- No non-Veo generator.
- No fallback video model unless TOP explicitly approves a tool change.

Video requirements:

- 9:16 vertical.
- 8-15 seconds.
- Human/use-case/product/CTA mood.
- Designed to drive link clicks.
- Product identity preserved.
- Must follow TOP's reference/prompt/style.

If Veo fails due to quota, billing, API, or spending cap, stop and report. Do not switch tools.

## Video post

After latest TOP approval or explicit instruction to post the generated video:

- Publish one video post.
- Use the same three-link set.
- Use female Thai admin voice.
- No AI/agent/internal names.
- No Sub ID or commission.
- Verify video attachment and permalink by API readback.

## Final verification checklist

A run is not complete until the final report confirms:

- Shopee API pass.
- Facebook API pass before publishing.
- Product filters pass.
- Facebook Ads Library research completed or fallback clearly labeled.
- Three affiliate links present.
- Image model is `gpt-image-2` / `gpt-image-2-high`.
- No image-generation fallback used.
- Five image posts published and verified.
- Every image post has one link comment.
- Every image post has five image-only comments with no text.
- No AI/agent/internal names in public captions/comments.
- No Sub ID/commission/internal leak.
- Video generated by Veo only.
- Video post published and verified when Veo is available and approval exists.
- Obsidian/Wiki run note saved without secrets.

## Failure handling

- Shopee API fail: stop before product/link/content work.
- Facebook API fail: draft only; no real publishing/commenting.
- Ads Library unavailable: label fallback research clearly.
- Affiliate link generation fail: stop before publishing.
- Product image fidelity fail: regenerate with `gpt-image-2` or stop.
- `gpt-image-2` unavailable: stop; do not switch image models.
- Veo unavailable/quota fail: stop; do not switch video tools.
- Facebook rate limit: stop, wait for cooldown, and retry safely.
